## 260-Character Description
OUTNA.ME lets you create small personal AI agents that keep working: they remember useful context, run on schedules, call tools and sub-agents, work through channels, and use Vercel Sandbox + Workflow to keep recurring work moving.

## Maker First Comment
Hey Product Hunt,

I built OUTNA.ME because I kept running into the same problem with AI tools: the useful work was not one better answer, it was continuity.

I wanted small personal agents that could:

- run on a schedule
- remember useful context for future runs
- use tools without becoming one giant assistant
- call sub-agents for bounded specialist work
- work through channels like chat and Slack
- keep their runtime state isolated

The Vercel Day fit is very literal. OUTNA.ME uses Vercel Sandbox for isolated agent state, Vercel Workflow for durable runs, AI SDK for model/tool work, and Chat SDK for product/channel surfaces.

I would love blunt feedback on three things:

1. Is the positioning clear?
2. Which first agent would you create?
3. What would make you trust an autonomous agent with recurring work?

No upvote ask. Comments, questions, and product criticism are much more useful.
